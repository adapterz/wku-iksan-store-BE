
# DB 문제 해결 안내

현재 스키마·검증 방법과 과거 작업 일지는 구분합니다. 이 문서는 운영 DB 변경 승인이 아닙니다.

| 확인 대상 | 기준 |
| --- | --- |
| 로컬 연결·권한·초기 데이터 | [개발 환경](../BE/DEVELOPMENT.md). 신규 로컬 DB와 기존 DB 준비를 구분 |
| 테이블·컬럼·제약 | [ERD](../../db/ERD.md)와 실제 `db/schema.sql`, 해당 `migrate_*.sql` 대조 |
| 스키마 누락 오류 | 실제 적용 이력을 먼저 확인. 운영에 `schema.sql`·`seed.sql` 재실행 금지 |
| 실제 SQL·동시성 재현 | [테스트 가이드](../BE/TESTING.md). 격리 로컬 DB에서만 실행, 임시 DB 생성·삭제 권한 필요 |
| 날짜 불일치 | [DB 날짜 기준](../BE/DATABASE_TIMEZONE.md). 저장 기준 확인 없이 전체 값에 9시간 가감 금지 |
| 운영 변경·복구 | [배포 절차](../../README.md#배포). 백업·구버전 호환성·적용 결과 확인 |

[DB 작업 일지](DEVLOG.md)의 SQL과 적용 예정 표시는 당시 기록입니다. 파일이 존재하거나 이슈가 닫혔다는 사실만으로 특정 운영 DB에 적용됐다고 판단하지 않습니다.
