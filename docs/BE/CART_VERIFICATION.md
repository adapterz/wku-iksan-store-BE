## 기존 FE 테스트 실패

`tests/page-urls.test.cjs`의 공유 메뉴용 DOM 모형이 존재하지 않는 모달 버튼에도 빈 객체를 반환하여 `confirmBtn.addEventListener is not a function`이 발생합니다.

- 이 테스트와 `public/js/component.js`는 장바구니 브랜치에서 수정하지 않았습니다.
- 수정 PR [#78 — URL 테스트 DOM 모형 오류 수정](https://github.com/adapterz/wku-iksan-store-FE/pull/78)이 OPEN인 것을 확인했습니다.
- 중복 수정을 하지 않았습니다. 해당 PR 반영 후 전체 FE 테스트를 재실행해야 합니다.

## 검증 경계

- MySQL 검증은 매번 새 임시 DB를 만들고 제거했습니다. 운영/기존 개발 DB의 데이터는 변경하지 않았습니다.
- 브라우저 확인용 별도 임시 DB만 로컬 프리뷰 실행 중 유지합니다.
- 이미지/반응형 디자인 최종 승인, 실제 모바일 기기, 운영 배포 검증은 수행하지 않았습니다.
- 실제 PG 결제/동시 재고 차감은 구현 범위가 아닙니다.
- API·ERD 초안의 팀 승인과 기존 계정 삭제 동시성 이슈 #85는 남아 있습니다.
- 실제 통합 테스트에서는 오류 주입으로 ER_SIGNAL_EXCEPTION, ER_DUP_ENTRY 로그를 의도적으로 발생시켜 전체 롤백을 확인했습니다.
- PR 업로드, develop/main 머지, 운영 마이그레이션은 하지 않았습니다.
