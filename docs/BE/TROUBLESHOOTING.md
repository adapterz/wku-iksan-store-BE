# BE 문제 해결 안내

기존에 확인한 문제와 재현·실행 안내를 연결합니다. 아래 링크의 날짜·환경을 확인하고, 같은 증상이라는 이유만으로 원인이 같다고 단정하지 않습니다.

| 증상·확인 대상 | 먼저 볼 문서 |
| --- | --- |
| 로컬 기동·포트·환경변수·로그인 쿠키 | [로컬 개발 환경](DEVELOPMENT.md) |
| 비밀번호 변경 후 기존 로그인 거절 | [세션 무효화](SESSION_INVALIDATION.md) — 의도된 401과 DB 장애 구분 |
| 반복 요청의 429 응답 | [요청 제한](API_RATE_LIMITS.md) — 회원/IP·API별 제한과 재시도 헤더 |
| 탈퇴와 선물 주문 동시 처리 | [탈퇴 동시성](ACCOUNT_WITHDRAWAL.md) — 회원 잠금·로컬 DB 재현 |
| 변경 전 상품 목록이 다시 표시됨 | [상품 목록 캐시](PRODUCT_LIST_CACHE.md) — 캐시 세대·구버전 혼용 주의 |
| 날짜가 9시간 다르게 표시됨 | [DB 날짜 기준](DATABASE_TIMEZONE.md) — 저장·직렬화·화면 표시 구분 |
| 취소 상세에 ‘오류’ 제목 표시 | [교환권 취소](GIFT_CANCELLATION.md#배포-확인-및-알려진-사항) — 알려진 표시 문제와 실제 사용 차단 구분 |

새 문제는 기준 커밋·환경·재현 순서·기대/실제 결과를 기록해 [#158](https://github.com/adapterz/wku-iksan-store-BE/issues/158)의 기존 항목과 중복 여부를 확인합니다. 민감한 값이나 사용자 개인정보는 로그·이슈에 그대로 올리지 않습니다.
